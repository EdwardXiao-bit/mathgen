进入使用 我是学生

学生也可以直接扫卷子上的二维码进来。

出题只是第一半。另一半是让这张纸印出来就能用：四栏、行距、字号、页边距，都在屏幕上先排好。卷子长到两三页也一样，预览里按 A4 分页，翻到第几页、缩放多少，都看得见。

六个维度，一个实时卷面

20 以内加减法 · 课堂小测

卷号 2610-0001

班级：________　姓名：________　学号：________　得分：________

    题量

    八到一百道都行。卷面按每行几道重新分栏，页数自己会算，不用手挪。

    每行几道

    两栏到六栏。低年级留宽一点，写竖式也不挤。

    字号

    十号到二十号。字号越大，一张纸能放的题越少，卷面会自己提示。

    页边距

    一到三厘米。装订边留够，打印店的机器才不会吃掉第一列。

    同一份卷子，
    五个样子。

    打印出来发给学生的那张纸。答案和卷面一起生成，页尾另附答案页。

    卷子长到好几页时，预览按 A4 一页页排下去，页间留一道缝；最后一页不满也画到页底。上面的页码栏能翻到每一页，缩放 50% 到 200%。

    发卷时分配卷号。二维码用的是老师电脑在局域网里的地址，投屏让学生扫。

    学生在手机上看到的样子：一道题一屏，填完点下一题，交卷就有分。

    谁交了什么，按人和按卷都能查；逐题对错、用时、得分，可以导出成表格。

    1. 出题。

      运算、范围、进位退位、题型、题量，勾完点生成。

    2. 改题。

      哪道不合适就单独换掉或删掉，卷面当场重排。

    3. 打印发卷。

      直接打印，或者导出 PDF 和 Word 交给打印店。预览里分好的页，打出来就是那几页。

    4. 交卷出分。

      学生扫码答题，交卷那一秒分数就在成绩页上了。

    学生那边，
    打开就能答。

    不用注册，也不用装任何东西。手机连上同一个局域网，扫卷子上的二维码，或者输入卷号，填一次姓名和学号，就能一题一屏地答；交卷当场出分，哪题错了、你写了什么，都列在下面。

    • 不装 App浏览器打开就是答题页，答完即走。
    • 一题一屏答题框占满一屏，数字键盘直接输，不用眯着眼找空格。
    • 交卷出分分数、答对几题、逐题对错，学生自己先看到。

    分数自己算，
    表格自己出。

    交完的卷子自动汇总：谁做了、几分、答对几题、用了多久，按人、按卷都能查。

    想装到另一台电脑上

    这台机器已经装好了，直接点上面的「进入使用」就行。换电脑、或者帮同事装，四条路任选一条，跑起来的是同一个服务，装完浏览器打开 127.0.0.1:8000 就是这一页。

    一键脚本

    Windows 上在 PowerShell 里跑一遍，脚本自己建环境、装依赖、下 Chromium。

    git clone https://github.com/EdwardXiao-bit/mathgen.git
cd mathgen
powershell -ExecutionPolicy Bypass -File scripts\start.ps1 -Lan
    Docker

    镜像里已经带了 Chromium，一条命令起来。

    docker run --rm -p 8000:8000 -v mathgen-data:/data \
  ghcr.io/edwardxiao-bit/mathgen:1.0.0-rc3
    npm 启动器

    有 Node 和 Python 就能用；第一次会装到 ~/.mathgen，之后是一秒启动。

    npx mathgen-cli@rc
    pip

    从 Release 下 wheel 装上，多一个 mathgen 命令。

    pip install mathgen_backend-1.0.0rc3-py3-none-any.whl
mathgen --host 0.0.0.0

    教室场景加 -Lan（或把地址设成局域网）：服务会打印本机地址，学生用手机连那个地址，或者扫卷面上的二维码。

    老师最常问的

    要联网吗？

    不用。系统跑在老师自己的电脑上，题目、成绩、学生姓名都在本机的一个数据库文件里；教室里靠局域网连，不用买服务器，也不用注册账号。

    学生的手机要装东西吗？

    不用装。扫码或者打开卷面地址，填一次姓名和学号，就可以逐题作答；下一次同一台设备不用再填。

    数据存在哪？

    老师电脑上的一个文件，换电脑时拷过去就行。没有云端同步，也就没有谁家的服务器能看见班里学生的名字。

    打印和导出差多少？

    预览、浏览器打印、导出 PDF 用的是同一份页面，不会出现预览好好的、印出来错位。导出前会先算容量，放不下会直接告诉你把字号调小到多少。

    出好的卷子还能改吗？

    能。单题可以换掉或删掉，版式随时调；已经发出去的卷是一份快照，想改就另存一份草稿再发，学生手里的卷号就不会变。

    卷子长到两三页呢？

    预览按 A4 一页页排下去，页间留一道缝，最后一页不满也画到页底；顶部页码栏可以翻到任意一页，缩放从 50% 到 200%。预览里是几页，打印和导出就是几页。

    下次上课前想接着用：把上面那条命令再跑一遍就行，卷子和成绩都还在你电脑里。
