## 1. 要解决的问题

小学老师出四则运算练习题时，从教辅书挑题、手抄或复印，**题量与难度不好控制，想换一套题又要重新翻书**；学生练习结果还要老师逐份手工批改。

本项目把这两件事做成一个本地网站：出题参数化、卷面可打印、判分自动化，且**完全跑在局域网内**——不依赖公网，教室断网也能用。

## 3. 范围

**本期做**：老师端出题（六维配置）→ 生成 → 预览改题 → 排版可调 → 打印 A4 / 导出 PDF / Word；答案版含答案、难度、考点、脱式过程；卷库与卷号复现；发卷（二维码 + 卷号）；学生端扫码、自主练习（滑杆选题量）、做老师发的卷、屏幕作答、自动判分；成绩列表与逐题明细、导出 CSV/Excel。

**本期不做**：手写 OCR 批改（后期）、竖式出题与排版（后期）、文字应用题（**不列入路线图**）、小数与分数四则（暂缓）、错题本与一键重练、账号 / 班级 / 学号体系、多人协作与云端题库。

> 逐条编号见 [`01-需求分析.md`](01-需求分析.md) §6 范围边界。

## 4. 关键约束（违反即返工）

| # | 约束 | 来源 |
| --- | --- | --- |
| C1 | **不依赖公网**：无 CDN、无外部 API、无域名备案；断网时老师端出题与打印仍可用 | NFR-1 / NFR-9 |
| C2 | **学生端接口不得下发 `answer` 与 `steps`**，判分一律在服务端 | 安全边界 |
| C3 | **预览 / 打印 / PDF 共用同一份 HTML**，不允许各走一套排版 | NFR-5 |
| C4 | **Word 只保证结构一致**（题号、题目、每行题数、答题空位），不追像素一致 | D33 |
| C5 | **出题引擎是纯函数**：`(config, seed) → questions`，不 import 数据库与框架 | NFR-4 / FR-E8 |
| C6 | **题目存快照，不靠重算**；卷发布后冻结，改题走另存副本 | D27 / D32 |
| C7 | **`docs/*.md` 是事实来源**，Word 是派生产物，禁止直接改 docx | D37 |
| C8 | **接口以 [`04-接口契约.md`](04-接口契约.md) 为准**，改动必须走决策记录 | §04 |
