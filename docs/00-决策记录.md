### 数值范围档位表（D16）

出题时**可多选组合**，并可叠加「特殊约束」开关：

| 档 | 范围 | 典型年级 |
| --- | --- | --- |
| R1 | 20 以内加减法 | 一年级 |
| R2 | 100 以内加减法（含进位 / 退位） | 一~二年级 |
| R3 | 表内乘除法（九九表范围内） | 二~三年级 |
| R4 | 两位数 × 一位数、两位数 ÷ 一位数 | 三~四年级 |
| R5 | 三位数 × 两位数、三位数 ÷ 两位数 | 四年级以上 |
| R6 | 四位数及以上多位数加减 | 四年级以上 |
| R7 | 老师自定义上限（填「最大不超过 N」） | 分层教学用 |

**特殊约束开关**（与档位正交）：是否进位 / 是否退位 / 除法是否必须整除 / 是否允许有余数 / 是否含括号。

### 关于 D4 与 D5 的关系
